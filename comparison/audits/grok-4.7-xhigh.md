## TOP FINDINGS

1. **Free map/power-up leak (regression).** `rooms.ts:488` broadcasts the same `room.seed` passed to `generateMap` at `:471`; `map.ts:44-72` derives castles and hidden contents from one `mulberry32` stream. Derivation: 500/500 exact, 9,081/9,081 hidden power-ups, 0.033ms per round; bot RNG (`:482`) replays 600/600.
2. **One frame kills the server, five ways.** Pre-auth `hello` with a non-string token (`net.ts:35`), and post-auth `join_room` (`rooms.ts:223`), `set_nickname` (`names.ts:15`), `queue_join` bad mode (`matchmaker.ts:28`), and in-match `input.dir` 2.5/true/""/[] (`rooms.ts:565` → `sim.ts:283`) all throw uncaught; no `uncaughtException` handler. Each confirmed exit 1 with `/health` down.
3. **Bots place balloons but still self-soak and Hard is not dominant.** 8-18 balloons/round; pre-tide self-soaks 18 Hard / 37 Easy per 200 rounds; Hard-vs-Easy 55% per round, 68% first-to-3; Hard-vs-Medium 58%. `danger.ts:143 walkable()` ignores player bodies that `sim.ts:251` blocks on.
4. **Fake HUD ping.** Client never sends `pong` (`client/net.ts:31` only stores `msg.rtt`), so `rooms.ts:534` reports `rtt=0` for all and `hud.ts:12` renders "0ms"; `prediction.ts:194` clock offset ignores latency.
5. **Ranked rooms and sessions leak.** `rooms.ts:856-865` never exits `results` for ranked; `slot.connected` is never cleared on close so `:878-881` GC never fires; `s.roomCode` stays set and blocks re-queue at `matchmaker.ts:23` until the client sends `leave_room`.

## ONE-LINE VERDICT

xhigh fixed the default's dead bot and widened spec coverage and tests, but regressed anti-cheat to a free seed leak and shipped a server that any guest can crash with a single malformed frame; unweighted mean **5.83/10** (7, 2, 5, 6, 7, 7).
